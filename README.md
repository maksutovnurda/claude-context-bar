# context-bar

Тонкая строка над полем ввода Claude Code (десктоп и терминал):

```
▬▬▬▬▬▭▭▭▭▭  42%  84k
▬▬▭▭▭▭▭▭▭▭  23%  02:14                              ● Remote
```

- две строки, у каждой своя полоска и свои цифры: сверху процент контекста и токены
  (полоска краснеет от 80%), снизу процент лимита за 5 часов и время до сброса как
  `hh:mm`
- в десктопе процент нарисован внутри самой полоски, 9 px — мельче, чем самый мелкий
  шаг текста (`caption`), который даёт движок; токены и время рядом остаются текстом
- тумблер Remote Control: серый — выключен, жёлтый — подключается, зелёный — включён

Строка обновляется сама: цифры приходят событием после каждого хода, а время до сброса
идёт вперёд, пока сессия простаивает, — писать в чат для этого не нужно.

`≈` значит «посчитано на месте, а не взято из ответа модели». У движка нет цифр, пока
сессия не получила первый ответ (только что открыта, возобновлена или сжата): тогда
заполнение считается локально, как `/context`, а лимит за 5 часов берётся из последнего
известного замера — он общий для аккаунта, а не для сессии. Как придёт первый ответ,
`≈` исчезает.

## Установка

В терминальной сессии Claude Code:

```
/plugin install context-bar --marketplace maksutovnurda/claude-context-bar
```

Из шелла:

```
claude plugin install context-bar --marketplace maksutovnurda/claude-context-bar
```

В десктопном приложении: + рядом с полем ввода → Plugins → Add marketplace `maksutovnurda/claude-context-bar` → Add plugin.

## Тумблер Remote в десктопе

Тумблер появляется только если разрешено читать состояние сессии; без правила строка не спрашивает разрешений и тумблер скрыт. Добавьте в `~/.claude/settings.json`:

```json
{ "permissions": { "allow": [
  "mcp__ccd_session_mgmt__get_session",
  "mcp__ccd_session_mgmt__set_remote_control"
] } }
```
